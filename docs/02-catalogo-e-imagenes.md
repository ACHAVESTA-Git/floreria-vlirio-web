## 3. Esquema de datos (Content Collection)

```ts
// src/content.config.ts
const productos = defineCollection({
  loader: glob({ pattern: '**/*.json', base: './src/content/productos' }),
  schema: ({ image }) => z.object({
    nombre: z.string(),
    categoria: z.enum(['ramos','buchones','cumpleanos','arreglos','box','tulipanes','extras']),
    ocasiones: z.array(z.enum(['amor','aniversario','cumpleanos','graduacion','condolencias','mejorate-pronto','nacimientos'])).default([]),
    descripcion: z.string(),
    precio: z.number(),
    precioOferta: z.number().optional(),   // si existe → aparece en "Ofertas"
    destacado: z.boolean().default(false), // si true → aparece en "Destacados"
    colores: z.array(z.string()).default([]),
    imagen: image(),                       // sin fondo (principal)
    imagenAmbiente: image().optional(),    // con fondo (galería del detalle)
    demo: z.boolean().default(false),      // true = dato/foto/descuento de ejemplo, validar con el cliente
  }),
});
```
El `slug` sale del nombre del archivo (`resplandor-dorado.json`). Si hay nombres duplicados ⚠️, agrega un sufijo (`edeliz-tulipanes`).
